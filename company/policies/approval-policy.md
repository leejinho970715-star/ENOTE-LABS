# approval-policy

LEVEL 1 내부 자료 정리·읽기·분석·초안·회의록·내부 테스트는 자동 허용한다. LEVEL 2 GitHub 쓰기/PR, Gmail 초안/발송/라벨, Calendar 변경, Figma 댓글, 외부 데이터 쓰기, AI 유료 호출, 게시/배포는 CEO 개별 승인이 필요하다. LEVEL 3 결제/계약/대량 삭제/운영 파괴/비밀 전송/권한 변경은 지원하지 않고 차단한다. 승인은 정규화한 작업 payload SHA-256, 대상, 실행자, 유효기간에 묶인다. 변경된 payload는 새 승인을 요청한다. 성공·실패·결과 불명 모두 승인은 재사용하지 않는다. 수정 요청은 새 작업을 생성한다.
