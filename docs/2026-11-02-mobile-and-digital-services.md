# 모바일 점검 및 디지털 자료 제작 서비스 검토

> 아래 최초 가격·원가 가정은 도입 당시 기록이다. 현재 판매 가격·범위는 `2026-11-02-digital-service-price-review.md`와 랜딩을 따른다.

## 판단

전자 카탈로그는 영업 자료, E-book은 제품 매뉴얼·고객 교육·온보딩 자료에 집중해 도입한다. 기존의 ‘작은 팀의 업무와 정보를 연결한다’는 사업 방향과 이어진다. 신규 SaaS 두 개를 추가하는 것이 아니라 고객의 원고·이미지를 활용하는 맞춤 제작 서비스다. 출판 유통·책 판매 수익·대필 사업은 이번 범위에 포함하지 않는다.

## 확인된 근거와 한계

- [수출바우처 카탈로그 제작 서비스](https://www.exportvoucher.com/pto/svm/serviceMenuDetail?svcInfoSeq=30437): 기업 대상 제작 서비스가 유료로 제공되는 사례다. 외국어 인쇄물·디자인 인력 범위가 달라 당사의 시작 가격과 직접 비교할 수 없다.
- [Adobe eCatalog 설명](https://experienceleague.adobe.com/en/docs/dynamic-media-classic/using/ecatalogs/quick-start-ecatalog): 카탈로그·브로슈어·매뉴얼을 웹 자료로 제공하는 활용 방식을 확인했다.
- [Adobe PDF 열람 분석 연동](https://developer.adobe.com/document-services/docs/overview/pdf-embed-api/howtodata): 열람 분석이 가능한 기술적 확장 사례다. 당사 기본 제공 기능으로 표기하지 않는다.

위 자료는 서비스 유형의 존재를 뒷받침한다. ENOTE-LABS의 실제 수주율, 시장 규모, 고객 지불 의사나 순이익을 입증하지 않는다. 출시 소개와 별도로 유료 파일럿이 필요하다.

고객이 확정 원고와 사용 권한이 있는 이미지를 제공한다. 호스팅·도메인·유료 이미지·추가 수정·집필·번역·EPUB·관리자·결제·CRM 연동·열람 통계는 별도 협의한다. 원고 검수와 파일/화면 확인 후 인수하며, 고객 자료를 공개 데모에 사용하지 않는다.

## 원가 관리 가정 — 실적·순이익 예측 아님

내부 시간당 원가를 KRW 30,000으로 가정하면 카탈로그 10시간은 KRW 300,000, E-book 6시간은 KRW 180,000의 직접 인건비다. 시작 제작비와 차이는 각각 KRW 200,000 / KRW 170,000이다. 여기서 고객 확보·협의·외부 도구·결제 수수료·일반 관리 비용 등이 추가 차감된다. 실제 세후 순이익이 아니다.

상담과 수정 시간을 포함해 기록하고, 허용 시간을 넘으면 원고·분량·수정 범위를 축소하거나 추가 견적을 낸다. 고객 확보는 기존 CRM·프로젝트 관리 상담 고객에게 제안하고, 제조·유통사의 상품 소개와 컨설팅·교육사의 안내서를 우선 검증한다. 첫 유료 3건에서 견적 수락, 실제 투입 시간, 수정량, 재의뢰 의사를 기록해 상품 유지·가격 조정을 결정한다. 자동 업데이트·자동 CRM 등록은 연동을 구현·검증한 경우에만 판매한다.

## 모바일 디자인 기준과 점검

- Pretendard, 본문 최소 14px. 작은 화면의 입력·선택·텍스트 영역은 16px로 iPhone 자동 확대 가능성을 줄인다.
- 일반 조작 영역 최소 44px, 주요 버튼 묶음 간격 12px. 설명형 카드는 내용에 따라 높이를 늘린다.
- 회사 사이트에 모바일 섹션 바로가기를 제공한다. 문의 버튼은 별도 영역과 일정한 간격을 갖는다.
- 작은 화면의 견적 단가는 한 줄 전체를 사용하고 삭제 조작 영역은 44×44px 이상으로 유지한다.
- 모달은 동적 화면 높이(dvh)를 사용하고 내부 스크롤을 허용한다. 표·칸반은 필요한 영역만 좌우 스크롤한다.
- 오렌지 테마·흰색 주요 버튼 글씨·기존 제품 심볼을 유지한다. Flownote favicon은 배경판 없는 오렌지 심볼이며 PNG·ICO·SVG에 투명도를 적용한다.

브라우저 화면 폭을 320 / 390 / 430 / 768 / 1024px로 바꾸어 랜딩을 검사했다. 네 제품의 대시보드는 320 / 390 / 768px와 주요 메뉴에서 글자 넘침·페이지 가로 스크롤·14px 미만 글씨를 확인했다. 화면 읽기 전용 숨김 텍스트와 의도적으로 스크롤하는 표/보드는 일반 콘텐츠 넘침과 구분한다. 실제 iOS Safari·Android 실기기/가상 키보드 검증을 대체하지 않는다.
