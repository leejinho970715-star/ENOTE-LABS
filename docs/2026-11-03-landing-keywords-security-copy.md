# 제품 검색 키워드와 보호 안내

2026-11-03 / CMO 김하린·CLO 한서윤 검토, CTO 관점의 구현

- CMO는 실제 기능 기준 제품별 키워드 4개를 제안했다. 검색량·전환율은 측정하지 않았고 순위 상승을 보장하지 않는다. Crewmemo의 전자결재 표현은 현재 범위를 분명히 하도록 ‘내부결재’로 좁혔다.
- 제품 소개에 보이는 해시태그 16개와 자연스러운 본문 설명을 추가했다. 클릭 기능이 없는 텍스트 태그이며 검색 링크나 숨겨진 키워드 목록이 아니다.
- 정적 HTML의 제품별 SoftwareApplication 구조화 데이터에 같은 키워드·설명·제공 범위를 담았다. 무료 데모와 제작 의뢰를 구분하며, 허위 평점·보안 인증·매출·전환 실적을 넣지 않는다.
- CLO는 무사고·문제없음 표현을 배제하고 회사별 접근 제한·비공개 파일·역할별 권한의 확인된 조치만 설명하도록 제안했다. 공통 보호 안내에 추가 점검·자료와 첨부파일 복구·국외 처리 절차가 남아 있으며 가상 자료로 체험해야 함을 표시했다.
- 이번 변경은 랜딩 콘텐츠와 스타일 변경이다. 새로운 침투시험이나 보안 인증이 아니다. Supabase 기본 유출 비밀번호 경고와 전체 운영 복구 미검증 상태를 해소했다고 표시하지 않는다.
