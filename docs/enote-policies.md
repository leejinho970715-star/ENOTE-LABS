# ENOTE-LABS 정책 문서와 푸터 모달

게시 버전: 2026-11-02 / 1.0. `studio/legal.mjs` 한 원본으로 푸터의 네이티브 dialog와 `/legal/privacy/`, `/legal/terms/` 전문 페이지를 생성한다. 전문 페이지는 noindex,follow이며 JavaScript 없이도 읽힌다. 모달 열람·닫기는 동의 처리로 저장하지 않는다. 동의 이력 수집·가입 동의 기능을 구현했다고 표시하지 않는다.

## 확인한 운영 사실

- 랜딩 문의는 클립보드 복사이며 서버 접수·자동 메일 발송이 아니다.
- 회원 인증은 Supabase, 회사별 자료는 DB/RLS와 비공개 Storage에서 처리한다.
- 프로젝트 정보 조회 결과 주 리전은 `ap-southeast-2`(호주 시드니). 한국 저장이라고 표시하면 안 된다.
- Vercel 호스팅과 Gmail/Telegram 직접 문의 채널을 사용한다.
- 월 구독 자동 결제는 미운영이며 가격은 작은 범위의 1회 제작비다.
- 셀프 탈퇴·자동 일괄 파기 기능은 없다. 삭제 요청은 이메일로 본인/회사 권한을 확인하는 수동 절차로 안내한다.
- 광고 픽셀·별도 방문 분석 SDK는 랜딩 코드에 없다. 필수 인증 및 샘플 자료는 브라우저 저장소를 사용한다.

## 확정되지 않은 부분

수탁계약, 국외 이전 근거 및 전체 처리국가/재수탁자, 인프라 로그·백업 소거 주기 검토는 미완료다. 이를 법적 검토 완료나 국외 이전 동의 완료로 표시하지 않고 공개 문서에도 보완 중임을 명시한다. 일반 고객 개인정보를 본격 수집하기 전에 실제 운영 조건을 확정하여 수정해야 한다. 보존 기간은 실제 처리 목적/법령 적용 여부에 따라 구분하며 단순 체험 전체를 거래기록 5년 보관 대상으로 보지 않는다. 정식 계약 전 법적 검토를 완료한 문서라는 주장을 하지 않는다.
