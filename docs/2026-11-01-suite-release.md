# ENOTE-LABS: 무료 이용·제품 연결·도표

## 실제 제공 범위

- 구현된 기능에 월 구독료·체험 만료를 적용하지 않는다. `af_orgs.free_access`는 기본 true이며 회사·프로젝트 권한과 운영 한도는 유지한다.
- 제작 제안: KRW 200,000 / 350,000 / 500,000. 기존 데모 기반의 작은 맞춤 작업이며 부가세·신규 대규모 개발·호스팅·외부 API·유지관리는 별도다.
- `/suite/`에서 CRM ↔ PMS 고객을 명시적으로 재사용한다. 이름으로 자동 병합하거나 기존 정보를 덮어쓰지 않는다.
- 수주 기회 → PMS 프로젝트를 중복 없이 생성한다. 기회 금액을 실제 계약금액·매출로 전환하지 않는다.
- PMS 작업 → Crewmemo 업무를 담당자 지정 후 연결한다. 연결한 상태만 양방향 동기화한다. 화면을 새로고침하면 다른 제품의 변경을 조회한다. 실시간 푸시는 제공하지 않는다.
- 양쪽 대표 관리자 확인 후 Flownote 회사를 연결하고 CSV 고객·프로젝트를 생성한다. 기존 Flownote 회사 권한을 자동 확대하지 않는다.
- Flownote 공개 대시보드는 샘플 조회, CSV 검사는 브라우저 기능이다. 보고서 작성·검수·승인 전체 화면은 로컬판 범위이며 클라우드 보고서 UI 전체 연결은 남아 있다.
- 통합 샘플은 같은 호스트의 브라우저 저장소를 쓴다. 서로 다른 배포 도메인의 별도 샘플 저장소까지 동기화하지 않는다. 회사 모드는 공통 DB를 사용하되 도메인별 로그인이 필요하다.

## 도표 및 UI

- Flownote: 최신 보고 상태, 프로젝트 기간, 고객·담당자 배분, 보고서 버전 범위.
- ProjectFlow: 단계·종료 일정, 작업 상태·마감, 자료 버전별 피드백, 견적 버전 총액.
- Follonote: 기회 단계·입력 금액, 유입 경로, 후속 연락 상태·기한.
- Crewmemo: 업무·결재 상태, 향후 7일 일정, 업무 마감.
- 도표는 현재 권한·조회 범위를 사용하며 수치표와 빈 자료 안내를 제공한다. 금액 누락은 합계에서 제외한다.
- 일반 작업 버튼 높이 44px, 그룹 간격 12px, 폼 간격 16px. 큰 데이터 행·이미지 핀은 별도 유형을 유지한다.
- 제품소개서 4종에 실제 도표 사진·읽는 방법·제품 연결 설명·무료 이용·제작비를 추가했다.

## 검증

- 단위 테스트 43개: 집계·KST 날짜·누락 금액·HTML 이스케이프·연결 중복·수주 조건·무료 권한 포함.
- 운영 DB의 합성 자료 트랜잭션 검증: 만료 후 무료 쓰기, 네 제품 연결, 중복 방지, 작업 상태 양방향 반영, 다른 회사 원본 차단·RLS 검증 후 전체 rollback. 영구 검증 계정·업무 자료를 남기지 않았다.
- Supabase security advisors: 경고 없음. 이 결과는 전체 침투 시험이나 보안 보장을 뜻하지 않는다.
- DB 측정 시 14,472,883 bytes (약 13.8 MiB), Storage 0 bytes. 초기 공개 테이블 37개 모두 RLS 적용, 연결 테이블 3개에도 RLS 적용.
- 390px·320px의 네 제품 주요 도표 및 연결 화면: 페이지·도표 가로 넘침 없음, 일반 버튼 44px 확인. 실제 모든 기종 인증은 아니다.
- 브라우저 샘플: 고객 연결·보고 기반 생성·팀 업무 연결·작업 변경에 따른 도표 갱신·고객 역할 내부 작업 숨김 확인.

## 남은 운영 조건

- 일반 고객용 SMTP는 준비되지 않았다. 가입 메일의 전체 고객 배달 검증은 완료되지 않았다.
- 새 연결 명령은 DB 트랜잭션과 브라우저 샘플로 검증했다. 실제 가입 고객을 통한 전체 HTTP 연결 흐름·복구·대용량·동시 사용자 부하 검증은 남아 있다.
- 기본 운영 한도는 용량 무제한 약속이 아니다. 자동 청구·결제·자동 메일·임의 웹사이트 자동 검수는 제공하지 않는다.
